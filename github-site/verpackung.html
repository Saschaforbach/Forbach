Funktioniert das System auch bei 1.200 Takten pro Minute?Does the system work at 1,200 cycles per minute?+
Ja — unsere Sensorik erfasst Schwingungen mit 25,6 kHz und Siegelkräfte mit bis zu 10 kHz Abtastrate. Selbst bei 1.200 Takten/min werden alle relevanten Messgrößen je Takt erfasst. Edge-Computing sorgt für Latenz < 50 ms.
Yes — our sensors capture vibrations at 25.6 kHz and sealing forces at up to 10 kHz sampling rate. Even at 1,200 cycles/min, all relevant parameters are captured per cycle. Edge computing ensures latency < 50 ms.
Kann das System Siegelnahtqualität inline bewerten?Can the system evaluate seal quality inline?+
Ja — durch Kombination von Siegelkraft, Temperaturprofil und optionaler Kamerainspektions-KI wird jede Siegelnaht bewertet. Undichte Packungen werden erkannt und ausgeschleust bevor sie die Linie verlassen — 100 % Inline-Qualitätskontrolle ohne Taktreduktion.
Yes — by combining sealing force, temperature profile and optional camera inspection AI, every seal seam is evaluated. Leaking packages are detected and rejected before leaving the line — 100% inline quality control without cycle reduction.
Wie wird das System an bestehende MES/ERP-Systeme angebunden?How is the system connected to existing MES/ERP systems?+
Über Standard-REST-API, OPC-UA oder MQTT. Wartungsaufträge werden direkt in SAP PM, Infor EAM, IFS oder eigene CMMS-Systeme übertragen. Schichtberichte und OEE-Daten werden automatisch exportiert. Keine manuelle Dateneingabe.
Via standard REST API, OPC-UA or MQTT. Maintenance orders are transferred directly to SAP PM, Infor EAM, IFS or custom CMMS systems. Shift reports and OEE data are automatically exported. No manual data entry.
